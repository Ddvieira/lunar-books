# Lunar Books 🌙📚

Lunar Books é uma livraria digital fictícia desenvolvida como projeto de portfólio, utilizando HTML5, CSS e JavaScript.

## Sobre o projeto

O projeto foi desenvolvido para praticar desenvolvimento web e criação de interfaces interativas, com foco em uma experiência de navegação simples e responsiva.

## Funcionalidades

- Catálogo de livros
- Pesquisa de livros
- Filtro por categorias
- Visualização de detalhes
- Sistema de favoritos
- Estante de livros favoritos
- Armazenamento dos favoritos no navegador
- Layout responsivo

## Tecnologias

- HTML5
- CSS
- JavaScript
- LocalStorage
